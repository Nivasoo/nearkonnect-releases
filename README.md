# NearKonnect for Android

**Your neighbourhood, connected.** Official Android app downloads for [NearKonnect](https://www.nearkonnect.com).

## Download

➡ **[Download the latest NearKonnect app (APK)](https://github.com/Nivasoo/nearkonnect-releases/releases/latest/download/NearKonnect.apk)**

Or open the download page: https://app.nearkonnect.com/download

## How to install
1. Tap the download link and wait for the download to finish.
2. Open the downloaded file (from the notification or the Downloads folder).
3. If the phone asks, allow "Install unknown apps" for your browser or file manager.
4. Tap Install, then Open. Log in with your email.

If it says "App not installed", remove the older NearKonnect app first and install again.
